## ActiveSG Crowd Finder

[Project documentation](activesg/README.md) · [Collector workflow](.github/workflows/activesg.yml) · [Dashboard source](activesg/site/index.html)

30-day collection of publicly available ActiveSG gym and pool occupancy (28 October–26 November 2026, Singapore time), with a map-first decision dashboard and weekly crowd-pattern consistency statistics.

The [GitHub Pages dashboard](https://spacecadet00.github.io/data/) is available after **Settings → Pages → Build and deployment → GitHub Actions** is enabled and a deployment succeeds.

Independent research project; not affiliated with ActiveSG or Sport Singapore.
